# bid-document-creator

标书制作全流程智能助手 —— 招标文件解析、结构规划、内容撰写、合规检查、Word格式输出。

**当前版本：v2.0.0（2026-10-19 自主训练升级）**

## 本次训练要点

- 消化官方标准招标文件体系：发改委九部委《标准招标文件》、财政部87号令《政府采购货物和服务招标投标管理办法》、多地公共资源交易中心真实范本。
- 新增 `references/official-standards.md`：评标办法体系对比、综合评分法真实权重区间、报价得分公式、否决投标三表、中小企业价格扣除、实质性条款标注规则、主观评分等级表述。
- `references/writing-guide.md` 新增「表述制作方向」专章：分级量化 / 逐条响应 / 数据承诺 / 评分导向 / 合规优先。

## 能力范围

- 工程建设、货物采购、服务类（含保安/物业/劳务外包等）通用多类型标书。
- 五阶段流程：招标文件解析 → 结构规划 → 内容撰写 → 合规检查 → 格式输出。
