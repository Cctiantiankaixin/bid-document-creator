## 写作基本原则

### 核心原则

1. **针对性**：所有内容必须围绕本项目，不能用通用模板套
2. **响应性**：逐条回应招标文件要求，不能遗漏任何实质性条款
3. **客观性**：用数据和事实说话，避免空泛形容词
4. **逻辑性**：结构清晰，层次分明，前后一致
5. **专业性**：使用行业规范术语，体现专业水平

### 写作流程

```
招标文件要求提取 → 评分点对应 → 章节内容规划 → 素材整理 → 正文撰写 → 自查修改
```

### 篇幅控制

| 章节类型 | 建议篇幅 | 说明 |
|---|---|---|
| 高分值技术章节 | 详细展开，占总篇幅40%-50% | 重点突出，充分论证 |
| 中分值章节 | 适度展开，占总篇幅20%-30% | 条理清晰，要点齐全 |
| 低分值/程序性章节 | 简洁带过，占总篇幅10%-20% | 格式规范，内容完整 |
| 资质证明部分 | 按要求提供材料 | 不额外展开 |

## 技术方案写作要点

### 常见结构

```
1. 项目理解与需求分析
2. 总体技术路线
3. 关键技术方案
4. 技术创新与优势
5. 技术难点与对策
```

### 写作技巧

**项目理解与需求分析**：
- 体现对项目背景的深入理解
- 点出项目的重点和难点
- 展示对招标人需求的精准把握
- 避免照搬招标文件原文

**总体技术路线**：
- 用流程图或框架图展示整体思路
- 说明各环节之间的逻辑关系
- 体现方案的系统性和完整性

**关键技术方案**：
- 这是得分重点，要详细展开
- 每个技术点说明：怎么做、为什么这么做、有什么优势
- 结合本项目具体情况，不能泛泛而谈
- 必要时用图表辅助说明

**技术难点与对策**：
- 识别项目真正的难点，不是老生常谈
- 对策要具体、可操作
- 体现解决复杂问题的能力

### 工程类技术方案示例框架

```
第五章 分部分项工程施工方案
  5.1 测量工程
    5.1.1 施工准备
    5.1.2 测量控制网建立
    5.1.3 主体结构测量
    5.1.4 沉降观测
    5.1.5 质量保证措施
  5.2 土方与基坑工程
    ...
```

## 实施方案写作要点

### 核心内容

```
1. 实施组织架构
2. 进度计划安排
3. 资源配置计划
4. 质量保证措施
5. 安全文明施工
6. 应急预案
```

### 写作技巧

**进度计划**：
- 必须有明确的时间节点，不能用"大概"、"左右"
- 区分关键线路和非关键线路
- 说明进度保证措施，不是只给一个时间表
- 横道图或网络图配合文字说明

**人员配置**：
- 列出关键岗位人员姓名、职务、资历
- 说明人员进退场计划
- 体现人员配置的合理性和充足性

**质量保证措施**：
- 建立质量管理体系框架
- 明确质量控制点和检验标准
- 说明质量通病的预防措施
- 体现全过程质量管理理念

**安全措施**：
- 安全管理体系
- 各分项工程安全技术措施
- 应急预案和救援组织
- 文明施工和环境保护措施

## 服务方案写作要点

### 服务方案核心框架

```
第五章 服务方案
  5.1 项目理解与需求分析
  5.2 服务总体思路
  5.3 服务内容与范围
  5.4 服务标准与规范
  5.5 服务流程设计
  5.6 服务质量保障
  5.7 应急响应机制
```

### 写作要点

**服务承诺要具体可考核**：
- ❌ 错误："提供优质服务，满足客户需求"
- ✅ 正确："7×24小时热线服务，故障响应时间不超过30分钟，一般故障2小时内解决，重大故障4小时内到场"

**服务流程要清晰**：
- 用流程图展示服务全过程
- 每个环节说明责任人、时间要求、输出成果
- 体现闭环管理（请求→处理→反馈→改进）

**服务团队要专业**：
- 项目负责人简历和资质
- 团队成员构成和分工
- 人员培训和考核机制

## 公司介绍与业绩写作

### 公司介绍写作

**结构**：
```
1. 公司概况（成立时间、注册资本、经营范围）
2. 资质荣誉
3. 技术实力
4. 管理体系
5. 同类项目经验概述
```

**写作要点**：
- 突出与本项目相关的优势
- 用数据说话（员工人数、年产值、资质等级）
- 不要长篇大论，控制在1-2页
- 重点展示与本项目匹配的能力

### 业绩写作

**业绩表格式**：

| 序号 | 项目名称 | 建设单位 | 合同金额 | 完成时间 | 项目内容 | 证明材料 |
|---|---|---|---|---|---|---|

**写作要点**：
- 优先排列与本项目最相似的业绩
- 业绩数量满足招标文件要求即可，不需要全部列出
- 每个业绩简要说明项目特点和我方承担的工作
- 附上合同关键页和验收证明
- 注意业绩时间范围符合招标文件要求

## 报价文件写作要点

### 基本原则

- **准确**：计算必须准确，大小写金额一致
- **完整**：所有清单项目都要报价，不能漏项
- **规范**：按招标文件提供的格式填写
- **合理**：报价符合市场行情，不低于成本价

### 常见问题

1. **大小写金额不一致** — 以大写为准，但会扣分
2. **单价和总价计算错误** — 逐项核对
3. **漏项** — 对照清单逐项检查
4. **报价超预算** — 编制前确认控制价
5. **选择性报价** — 只能有一个报价

## 常用表述模板

### 投标函常用结尾

```
我方已仔细研究了________（项目名称）招标文件的全部内容，愿意以人民币（大写）________元（¥________）的投标总报价，工期________（日历天），按合同约定实施和完成承包工程，修补工程中的任何缺陷，工程质量达到________。

我方承诺在投标有效期内不修改、撤销投标文件。

随同本投标函提交投标保证金一份，金额为人民币（大写）________元（¥________）。

如我方中标：
（1）我方承诺在收到中标通知书后，在中标通知书规定的期限内与你方签订合同；
（2）随同本投标函递交的投标函附录属于合同文件的组成部分；
（3）我方承诺按照招标文件规定向你方递交履约担保；
（4）我方承诺在合同约定的期限内完成并移交全部合同工程。
```

### 技术方案开头常用表述

```
一、项目理解
本项目为________工程，位于________，主要建设内容包括________。我方经过认真研究招标文件和现场踏勘，对本项目的特点和难点有以下认识：

1. ________
2. ________
3. ________

针对以上特点和难点，我方制定了以下施工方案，确保工程优质、高效、安全完成。
```

### 服务承诺常用表述

```
二、服务承诺
我方郑重承诺：
1. 质量承诺：本项目质量保证期为________，质保期内免费提供维修服务。
2. 响应时间：接到故障通知后，________小时内响应，________小时内到达现场。
3. 培训承诺：为甲方提供________次免费培训，确保相关人员熟练操作。
4. 维保承诺：质保期满后，提供终身维护服务，只收取成本费用。
5. 违约责任：如我方未能履行上述承诺，愿意承担相应的违约责任。
```

## 表述制作方向（官方口径与评分导向）

本技能经对发改委九部委《标准招标文件》、财政部87号令及多地公共资源交易中心发布的真实招标文件范本进行研读训练，确立以下"表述制作方向"，作为全篇措辞与语气的总基调。官方规则细节见 `references/official-standards.md`。

### 方向一：用"分级量化"替代"主观溢美"

评分主观项（方案优劣、服务承诺）在评标中按等级给分。撰写时把模糊形容词替换为可分级、可量化的表述：

- ❌ "我们提供最优质、最专业的服务"
- ✅ "按优/良/中/可/差（90-100 / 80-89 / 70-79 / 60-69 / 60以下）分级标准，我方方案在……方面达到优级：具体表现为……"
- 实操：每个主观章节主动预设评审等级锚点，用"满足 / 优于（正偏离）/ 符合 / 负偏离"四类规范用语自评，让评委易给高分。

### 方向二：用"逐条响应"替代"自由发挥"

招标文件以"投标人须知前附表""技术规格""商务条款"列出实质性要求，且按87号令须加黑加粗标明。撰写技术/商务响应时：

- 采用"招标要求 → 我方响应 → 偏离说明"三步结构
- 对每一项实质性条款明确写"完全响应，无偏离"或列明正偏离/负偏离
- 禁止遗漏任何加黑加粗的实质性条款，否则触发否决投标

### 方向三：用"数据承诺"替代"口号承诺"

服务类评分常设"服务承诺和质量保证"主观分，承诺必须可考核：

- ❌ "快速响应、优质服务"
- ✅ "7×24小时热线，故障30分钟内响应，一般故障2小时解决，重大故障4小时到场，逾期未达按合同价款0.5%/日承担违约金"

### 方向四：篇幅与分值正比（评分导向）

综合评分法下，分值权重决定篇幅：

- 技术/方案分占比高（工程可达30%、服务可达60%）→ 详细展开，占篇幅40%-60%
- 价格分由报价决定，标书不直接影响，但须确保计算准确、不超最高限价
- 资信/业绩为客观分，准确对应即可，不额外渲染

### 方向五：合规优先于文采

否决投标条款（形式/资格/响应性三表）是出局红线，任何文采都不如"签字盖章齐全、报价唯一、资质有效、在有效期内、未超限价"重要。撰写时优先核对 `references/compliance-checklist.md` 与 `references/official-standards.md` 的否决清单。

## 常见写作错误与避坑

### 内容类错误

| 错误类型 | 表现 | 后果 | 改进方法 |
|---|---|---|---|
| 通用模板化 | 内容与本项目无关，放哪个项目都能用 | 得分低 | 针对项目具体情况撰写 |
| 答非所问 | 没有回应招标文件的具体要求 | 扣分或废标 | 逐条对应招标文件要求 |
| 数据不实 | 业绩、人员、参数造假 | 废标+信誉处罚 | 所有数据基于真实材料 |
| 前后矛盾 | 工期、人员、数据前后不一致 | 影响评分印象 | 完成后全文通读检查 |
| 过度承诺 | 承诺超出能力范围 | 中标后无法履约 | 承诺要实事求是 |

### 形式类错误

| 错误类型 | 表现 | 后果 | 改进方法 |
|---|---|---|---|
| 格式错误 | 不按招标文件提供的格式填写 | 扣分或废标 | 严格按格式模板 |
| 编号混乱 | 章节编号不连续，层级不清 | 影响阅读体验 | 统一编号规则 |
| 错别字多 | 错字、漏字、标点错误 | 不专业印象 | 完成后校对 |
| 字体不统一 | 不同章节字体字号不一致 | 不规范 | 统一设置样式 |
| 目录错误 | 目录页码与正文不符 | 不严谨 | 自动生成目录后更新 |

### 避坑 checklist

- ☐ 是否逐条回应了招标文件的所有要求？
- ☐ 每个评分点是否都有对应内容？
- ☐ 技术方案是否针对本项目？
- ☐ 业绩是否满足招标文件要求？
- ☐ 所有数据是否真实准确？
- ☐ 大小写金额是否一致？
- ☐ 是否有错别字和语句不通顺的地方？
- ☐ 格式是否符合招标文件要求？
- ☐ 目录页码是否正确？
- ☐ 签字盖章位置是否都标注了？
