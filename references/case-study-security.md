# 保安服务外包标书案例参考

> 本案例基于禹江物业保安全业务外包服务项目提炼，作为物业服务/安保外包类标书的标杆参考。适用于保安服务、秩序维护、物业安保、场馆安保等服务类项目。

## 一、项目概况

| 项目 | 内容 |
|---|---|
| 项目名称 | 禹江物业保安全业务外包服务项目（二次） |
| 招标人 | 安徽禹江物业有限公司 |
| 项目类型 | 服务类 - 保安服务外包 |
| 服务范围 | 园区、办公楼、场馆等全域安保值守、秩序维护、安全防护 |
| 服务点位 | 龙湖、文化广场、古民居、档案馆、规划馆、文联、大剧院、少年宫、大明园等多项目点 |
| 服务期限 | 3年（1+1+1模式，一年一签） |
| 特殊资质 | 公安机关核发的《保安服务许可证》 |
| 付款方式 | 按月付款 |
| 评标方法 | 一般综合评分法 |

## 三、与劳务外包标书的差异对比

| 维度 | 劳务外包（天然气项目） | 保安服务外包（禹江物业） |
|---|---|---|
| 核心工作 | 生产辅助、后勤支持、前台服务 | 安保值守、秩序维护、安全防范 |
| 资质要求 | 一般服务资质即可 | 必须有《保安服务许可证》 |
| 人员特点 | 岗位多元（18类），要求各异 | 岗位相对统一（保安），体能要求高 |
| 重点内容 | 人员管理、培训、薪酬 | 安全管理、应急处置、服务规范 |
| 考核重点 | 人员到岗率、满意度 | 安全事件发生率、响应速度 |
| 风险点 | 用工合规、人员流失 | 安全责任、应急能力 |

## 四、保安服务类标书写作要点

### 4.1 项目理解部分

**写作重点：**
- 体现对物业安保工作特殊性的理解：点多面广、人员流动大、安全责任重
- 突出多项目点位管理的统筹能力：如何统一标准、统一调度
- 识别场馆类安保的特殊要求：大型活动保障、人流管控

**加分表述：**
> "本项目服务点位涵盖办公楼、文化场馆、公共空间等多种业态，各点位安保要求差异较大。我方将针对不同业态制定差异化的安保方案，同时建立统一的管控标准，确保服务质量均衡。"

### 4.2 岗位设置与人员配置

**必须包含：**
- 岗位清单表：每个点位的岗位数量、班次、人数
- 排班制度：三班倒/两班倒，交接班时间
- 人员资质要求：年龄、身高、体能、退伍军人优先等
- 储备人员机制：人员离职时的补位保障

**评分技巧：**
- 用表格清晰展示各点位人员配置
- 突出储备人员池规模（如"储备人员按在岗人数10%配置"）
- 说明人员背景审查机制（无犯罪记录等）

### 4.3 应急预案部分

这是保安服务类标书的**核心得分点**，必须详细展开：

**标准应急预案结构：**
```
X.X  XX突发事件应急预案
  X.X.1 事件分级与判定标准
  X.X.2 应急组织架构与职责
  X.X.3 处置流程
    X.X.3.1 发现与报告
    X.X.3.2 先期处置
    X.X.3.3 升级响应
    X.X.3.4 后期处理
  X.X.4 应急物资准备
  X.X.5 与甲方/公安/消防的联动机制
```

**必须覆盖的应急场景：**
1. 火灾事故
2. 治安事件（斗殴、盗窃、闯入）
3. 群体性事件/大型活动人流管控
4. 极端天气（暴雨、暴雪、高温）
5. 公共卫生事件
6. 设备故障/停电

### 4.4 服务质量标准

**量化指标是关键：**
- 人员到岗率：≥98%
- 投诉响应时间：≤15分钟
- 问题整改率：100%
- 巡查到位率：≥99%
- 客户满意度：≥90分

**避坑：**
- 不要只写"提供优质服务"，要有具体可考核的指标
- 量化指标要合理，既体现高标准，又要有可实现性

## 五、评分点对应策略

| 评分项 | 对应章节 | 写作策略 |
|---|---|---|
| 服务方案合理性 | 第2-3章 | 分点位、分业态细化方案，体现针对性 |
| 人员配置方案 | 第3.1章 + 第4章 | 岗位表+培训体系+储备机制 |
| 应急处置能力 | 第5章 | 预案齐全+流程清晰+演练计划 |
| 服务质量保障 | 第7章 | 三级检查+投诉处理+持续改进 |
| 项目团队配置 | 第8章 | 负责人经验+骨干人员资质 |
| 企业业绩 | 第9章 | 类似物业/场馆安保项目业绩 |
| 报价合理性 | 报价部分 | 按月计费、人员成本明细 |

## 六、保安服务类标书常见废标点

1. **无保安服务许可证** — 资质门槛，直接废标
2. **人员配置不足** — 岗位数量不满足要求
3. **应急预案缺失** — 关键场景无预案
4. **报价低于成本** — 恶意低价竞争
5. **服务期限不响应** — 不接受3年服务期
6. **不接受按月付款** — 商务条款重大偏离

## 七、篇幅参考

| 项目规模 | 标书建议篇幅 | 说明 |
|---|---|---|
| 单点位小型项目 | 30-50页 | 简洁明了，重点突出 |

| 大型综合体/场馆群 | 100-150页 | 详细全面，应急预案充分 |

### 实战调整经验

1. **二级标题数量控制**：第一节二级标题从28个合并到20个左右为宜，太多会导致目录冗长
2. **点位全覆盖**：9个点位必须全部覆盖，不能遗漏任何一个
3. **应急预案要全**：至少6大类应急预案，每类单独成节
4. **表格数量**：60页方案约包含15个左右的数据表格
5. **篇幅分配**：三大节大致按2:2:2的比例分配篇幅

### 常见问题与修正

| 问题 | 修正方法 |
|---|---|
| 页数不够 | 扩充各小节内容，增加专项方案（如反恐防暴、节假日安保） |
| 标题层级错 | x.y为二级，x.y.z为三级，重新检查大纲级别 |
| 点位遗漏 | 列出所有点位清单，逐一对应检查 |
| WPS打不开 | 重新生成干净文档，用标准样式避免XML损坏 |
| 表头有底纹 | 改为白色背景，仅保留边框 |
