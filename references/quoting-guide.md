## 报价基本原则

1. **不超预算**：投标报价不得超过招标控制价/最高投标限价，否则直接废标
2. **不漏项**：招标文件工程量清单中的每一项都必须报价，漏项视为已包含在其他项目中
3. **不低于成本**：报价不得低于企业成本价，否则可能被认定为恶意低价竞标
4. **唯一报价**：只能有一个报价，不接受选择性报价或有条件报价
5. **大小写一致**：大写金额和小写金额必须一致，不一致时以大写为准

## 报价计算规则

### 1. 单价×数量=合价
- 每一项的合价 = 单价 × 数量
- 注意单位换算（如吨和千克、平方米和公顷）

### 2. 分部分项合计
- 各分项合价相加 = 分部分项工程费合计

### 3. 措施项目费
- 安全文明施工费通常按规定费率计算，不可竞争
- 其他措施费根据施工方案测算

### 4. 规费和税金
- 规费：按国家和地方规定费率计算
- 税金：增值税，一般计税方法税率9%（建筑服务）

### 5. 总报价汇总
```
总报价 = 分部分项工程费 + 措施项目费 + 其他项目费 + 规费 + 税金
```

### 6. 计算注意事项
- 保留两位小数
- 四舍五入时注意误差累积，最后一项调整平衡
- 暂列金额、暂估价按招标文件给定金额填写，不得改动

## 大小写金额转换规则

### 大写数字对照表

| 小写 | 大写 | 小写 | 大写 |
|---|---|---|---|
| 0 | 零 | 5 | 伍 |
| 1 | 壹 | 6 | 陆 |
| 2 | 贰 | 7 | 柒 |
| 3 | 叁 | 8 | 捌 |
| 4 | 肆 | 9 | 玖 |
| 10 | 拾 | 100 | 佰 |
| 1000 | 仟 | 10000 | 万 |
| 100000000 | 亿 | | |

### 转换示例

| 小写金额 | 大写金额 |
|---|---|
| 1,234.56 | 人民币壹仟贰佰叁拾肆元伍角陆分 |
| 100,000.00 | 人民币壹拾万元整 |
| 1,000,000.00 | 人民币壹佰万元整 |
| 123,456,789.12 | 人民币壹亿贰仟叁佰肆拾伍万陆仟柒佰捌拾玖元壹角贰分 |

### 转换规则
1. 前面加"人民币"字样
2. 整数后面加"整"字
3. 有角分的写到角分为止，分位为0时写"整"
4. 连续多个零只写一个"零"
5. 万位、亿位要单独标注

### 快速验证方法
- 大写金额倒过来读一遍，和小写对照
- 注意检查"万"、"亿"位是否正确
- 注意检查"零"的位置是否正确

## 报价常见错误与检查

### 高频错误清单

| 错误类型 | 表现 | 后果 | 检查方法 |
|---|---|---|---|
| 大小写不一致 | 大写和小写金额对不上 | 以大写为准，可能扣分 | 大写和小写逐位对照 |
| 计算错误 | 单价×数量不等于合价 | 总价错误，可能废标 | 逐项重新计算 |
| 合计错误 | 分项相加不等于总计 | 总价错误 | 重新汇总计算 |
| 漏项 | 清单中有项目没报价 | 视为已包含，可能亏损 | 对照清单逐项核对 |
| 超预算 | 报价超过控制价 | 直接废标 | 和招标控制价对比 |
| 小数点错误 | 小数点位置错了 | 价格差10倍/100倍 | 检查金额数量级 |
| 单位错误 | 单位换算错了 | 价格错误 | 核对单位和数量 |

### 报价检查 Checklist

- ☐ 投标总报价是否超过最高投标限价？
- ☐ 大小写金额是否完全一致？
- ☐ 每一项合价 = 单价 × 数量 是否正确？
- ☐ 各分项合计是否正确？
- ☐ 总报价 = 各部分之和 是否正确？
- ☐ 是否有漏报的项目？
- ☐ 暂列金额、暂估价是否按招标文件填写？
- ☐ 安全文明施工费是否按规定费率计算？
- ☐ 税金费率是否正确？
- ☐ 报价是否低于成本价？（恶意低价风险）

## 报价策略提示

### 1. 不平衡报价
- 早日收回款项的项目（如土方、基础）可以适当报高
- 后期项目（如装饰、安装）可以适当报低
- 预计工程量会增加的项目单价报高，减少的报低
- **注意：** 不平衡幅度不要太大，否则可能被判定为不合理报价

### 2. 报价决策考虑因素
- 竞争对手数量和实力
- 项目利润空间
- 企业当前经营状况（是否需要冲业绩）
- 后续合作机会

### 3. 报价红线
- ❌ 绝对不能超过招标控制价
- ❌ 绝对不能有两个不同的报价
- ❌ 绝对不能漏项后在投标函里说明"另行报价"
- ✅ 报价前确认所有计算都经过复核

## 附：报价计算快速验证脚本

```python
# 报价计算验证示例
items = [
    {"name": "土方工程", "price": 50.0, "qty": 1000},
    {"name": "混凝土工程", "price": 450.0, "qty": 500},
    {"name": "钢筋工程", "price": 4800.0, "qty": 50},
]

total = 0
for item in items:
    subtotal = item["price"] * item["qty"]
    print(f"{item['name']}: {item['price']} × {item['qty']} = {subtotal:,.2f}")
    total += subtotal

print(f"\n分部分项合计: {total:,.2f}")
print(f"大写: 【需人工核对】")
```
