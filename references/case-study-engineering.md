# 工程施工类标书案例参考

> 本参考基于典型工程施工项目标书结构提炼，作为工程类标书的标杆参考。适用于房屋建筑、市政工程、装饰装修、机电安装等施工类项目。

## 一、工程标书整体架构

工程标书通常分为**技术标（施工组织设计）**和**商务标（报价+资质）**两大部分。

```
投标文件
├── 第一部分 商务标
│   ├── 投标函及附录
│   ├── 法定代表人身份证明
│   ├── 授权委托书
│   ├── 投标保证金
│   ├── 已标价工程量清单
│   ├── 项目管理机构
│   └── 资格审查资料
│
└── 第二部分 技术标（施工组织设计）
    ├── 编制说明与依据
    ├── 工程概况
    ├── 施工部署
    ├── 施工进度计划
    ├── 分部分项工程施工方案
    ├── 资源配置计划
    ├── 质量保证措施
    ├── 安全生产保证措施
    ├── 文明施工与环境保护
    ├── 季节性施工措施
    ├── 施工现场平面布置
    └── 协调配合措施
```

## 二、技术标核心章节写作要点

### 2.1 编制说明与编制依据

**写作要点：**
- 说明编制目的：指导本工程施工，确保质量、安全、工期目标
- 列出编制依据：招标文件、施工图纸、国家规范、地方标准、现场踏勘情况
- 列出主要规范清单（体现专业性）：
  - 《建筑工程施工质量验收统一标准》GB 50300
  - 《混凝土结构工程施工质量验收规范》GB 50204
  - 《建筑施工安全检查标准》JGJ 59
  - 等等

**避坑：**
- 不要只写"根据招标文件和图纸"，要列出具体规范名称和编号
- 规范要注意现行有效版本，不要用过时的

### 2.2 工程概况

**写作结构：**
```
2.1 项目基本情况
    - 项目名称、地点、建设单位、设计单位、监理单位
    - 建设规模：建筑面积、层数、高度、结构形式
    - 承包范围：土建、安装、装饰等
    - 质量要求：合格/鲁班奖/省优
    - 工期要求：XX日历天

2.2 建筑设计概况
    - 建筑功能、层高、门窗、装饰做法

2.3 结构设计概况
    - 结构形式、基础形式、抗震等级、混凝土强度等级

2.4 工程重点难点分析
    - 重点：XX方面是本工程关键
    - 难点：XX方面施工难度大
    - 对策：针对难点制定专门措施
```

**写作技巧：**
- 重点难点分析要具体，不要泛泛而谈
- 每个难点后面跟着应对思路，体现"发现问题-解决问题"的能力

### 2.3 施工部署

**核心内容：**
1. **施工总体目标**：质量目标、安全目标、工期目标、环保目标
2. **项目管理组织机构**：项目经理→技术负责人→各部门负责人→各班组长
3. **施工任务划分**：各分包单位的工作范围
4. **施工顺序**：先地下后地上、先主体后围护、先结构后装饰
5. **流水段划分**：平面分区、竖向分层组织流水施工

**关键评分点：**
- 组织机构图是否清晰
- 各岗位职责是否明确
- 施工顺序是否合理

### 2.4 施工进度计划

**必须包含：**
1. **总进度计划横道图/网络图**
2. **关键线路分析**：哪些工序是关键路径，延误就影响总工期
3. **各阶段工期安排**：
   - 基础工程：XX天
   - 主体结构：XX天
   - 装饰装修：XX天
   - 安装工程：XX天
   - 竣工验收：XX天
4. **进度保证措施**：
   - 组织措施：例会制度、进度跟踪
   - 技术措施：优化施工方案
   - 资源措施：人、材、机保障
   - 经济措施：奖惩制度

**避坑：**
- 不要只给一个时间表，要说明怎么保证进度
- 进度计划要和招标文件要求的工期匹配，不要超额太多也不要不足

### 2.5 分部分项工程施工方案

这是技术标的**核心得分点**，篇幅占比最大。

**典型章节结构：**
```
5.1 测量工程
    5.1.1 施工准备
    5.1.2 测量控制网建立
    5.1.3 主体结构测量
    5.1.4 沉降观测
    5.1.5 质量保证措施

5.2 土方与基坑工程
    5.2.1 土方开挖
    5.2.2 基坑支护
    5.2.3 降水排水
    5.2.4 基坑监测

5.3 基础工程
    5.3.1 桩基工程
    5.3.2 承台基础
    5.3.3 基础底板

5.4 主体结构工程
    5.4.1 模板工程
    5.4.2 钢筋工程
    5.4.3 混凝土工程
    5.4.4 砌体工程

5.5 装饰装修工程
    5.5.1 室内装饰
    5.5.2 外墙装饰
    5.5.3 门窗工程

5.6 屋面工程

5.7 机电安装工程

5.8 消防工程
```

**写作要点：**
- 每个分项工程按"施工准备→工艺流程→操作要点→质量标准→安全措施"展开
- 关键工艺要详细，体现技术实力
- 采用新工艺、新技术要重点突出（加分项）

### 2.6 质量保证措施

**结构框架：**
1. **质量管理体系**：ISO9001体系，项目经理为第一责任人
2. **质量控制标准**：达到国家验收规范合格标准
3. **质量控制点设置**：
   - 关键工序：钢筋、模板、混凝土等
   - 特殊过程：防水、焊接等
4. **质量通病防治**：
   - 混凝土裂缝防治
   - 墙体渗漏防治
   - 抹灰空鼓开裂防治
5. **质量检查制度**：三检制（自检、互检、交接检）

**加分项：**
- 提出创优目标（如"确保省优质工程"）
- 列出具体的质量奖惩制度

### 2.7 安全生产保证措施

**结构框架：**
1. **安全管理体系**：项目经理为安全第一责任人
2. **安全目标**：零死亡、零重伤
3. **安全技术措施**：
   - 高处作业安全
   - 脚手架安全
   - 施工用电安全
   - 起重吊装安全
   - 基坑作业安全
4. **应急预案**：高处坠落、坍塌、火灾等事故应急处置
5. **文明施工**：围挡、扬尘控制、噪声控制、材料堆放

## 三、商务标核心要点

### 3.1 项目管理机构

**必须包含：**
- 项目经理简历表（附注册建造师证、安全B证）
- 技术负责人简历表（附职称证）
- 主要管理人员简历表（施工员、质量员、安全员、资料员等）

**评分技巧：**
- 项目经理资质越高越好（一级建造师优于二级）
- 项目经理有同类工程业绩是加分项
- 班子人员齐全、证件齐全

### 3.2 资格审查资料

**业绩要求：**
- 近X年完成X个类似工程
- 单个合同额不低于XX万
- 附合同关键页和竣工验收证明

**业绩展示技巧：**
- 优先列规模最大、最类似的项目
- 每个业绩简要说明工程特点
- 按招标文件要求的数量列，不要多也不要少

## 四、工程标书评分点对应表

| 评分项 | 分值占比 | 对应章节 | 写作策略 |
|---|---|---|---|
| 施工方案合理性 | 25-30% | 第5章 分部分项施工方案 | 关键工艺详细展开，突出技术优势 |
| 施工进度计划 | 10-15% | 第4章 施工进度计划 | 横道图+关键线路+保证措施 |
| 质量保证措施 | 10-15% | 第7章 质量保证措施 | 体系+控制点+通病防治 |
| 安全文明施工 | 10-15% | 第8-9章 安全+文明施工 | 目标+措施+应急预案 |
| 项目班子配置 | 10% | 商务标 项目管理机构 | 项目经理资质+班子齐全 |
| 企业业绩 | 10% | 商务标 资格审查资料 | 类似业绩数量+规模 |
| 施工平面布置 | 5% | 第11章 现场平面布置 | 合理紧凑+分阶段布置 |
| 资源配置计划 | 5% | 第6章 资源配置 | 人材机配置合理 |

## 五、工程标书常见废标点

1. **项目经理有在建工程** - 很多地区限制
2. **资质等级不够** - 施工总承包几级对应多少规模
3. **安全生产许可证过期** - 工程类必须
4. **报价超过最高投标限价** - 直接废标
5. **投标文件未按要求装订/密封** - 形式性废标
6. **关键人员证书不齐全** - 安全员C证、质量员等
7. **业绩数量不够** - 少一个都不行

## 六、工程标书篇幅参考

| 项目规模 | 技术标建议篇幅 | 说明 |
|---|---|---|
| 小型工程（<1000万） | 50-80页 | 简洁明了，重点突出 |
| 中型工程（1000-5000万） | 100-150页 | 常规深度 |
| 大型工程（>5000万） | 200-300页 | 详细全面 |

**注意：** 篇幅不是越多越好，要根据评分分值分配篇幅，高分值章节多写，低分值章节简洁带过。
