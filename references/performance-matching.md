## 业绩要求解读

招标文件中的业绩要求通常包含以下要素，需要逐条拆解：

### 常见业绩要求要素

| 要素 | 说明 | 示例 |
|---|---|---|
| 时间范围 | 近X年，从某时间起算 | "近3年（2023年1月1日至今）" |
| 数量要求 | 需要X个类似项目 | "不少于3个类似工程" |
| 规模要求 | 单个项目合同额不低于XX万 | "单项合同额不低于500万元" |
| 类似性要求 | 什么算"类似"工程 | "房屋建筑工程"、"同类服务项目" |
| 业绩主体 | 必须是本公司，还是可以是子公司 | "投标人本单位" |
| 证明材料 | 需要什么证明 | "合同关键页+竣工验收报告" |

### 解读要点
- **时间起算点**：注意是从投标截止日倒推，还是从某个固定日期开始
- **类似工程定义**：招标文件对"类似"有明确界定的，严格按界定执行；没有明确界定的，按行业惯例判断
- **业绩有效性**：已竣工的才算，在建工程通常不算业绩
- **母子公司业绩**：一般母子公司业绩不能互相借用，除非招标文件明确允许

## 业绩筛选标准

从公司业绩库中筛选最匹配的项目，按以下维度评估：

### 筛选维度权重

| 维度 | 权重 | 说明 |
|---|---|---|
| 项目类型相似性 | 30% | 工程类型、服务内容是否一致 |
| 项目规模匹配度 | 25% | 合同额、建筑面积、服务人数等 |
| 项目复杂度 | 15% | 技术难度、管理难度是否相当 |
| 时间远近 | 15% | 越近的业绩越新，越有说服力 |
| 业主单位类型 | 10% | 同行业、同性质业主优先 |
| 获奖情况 | 5% | 获过奖的业绩加分 |

### 筛选步骤

1. **第一步：按硬指标筛选**
   - 时间范围内的
   - 规模达标的
   - 类型符合要求的

2. **第二步：按匹配度排序**
   - 从符合硬指标的业绩中，按上述6个维度打分排序
   - 选出匹配度最高的前N个

3. **第三步：按招标文件要求数量精选**
   - 要求3个就选3个，不要多也不要少
   - 多选可能暴露短板，少选可能不满足要求

## 匹配度评估方法

### 相似性评估表

对每个候选业绩打分（1-10分）：

| 评估项 | 评分标准 | 本项目要求 | 业绩A得分 | 业绩B得分 |
|---|---|---|---|---|
| 工程类型 | 完全一致=10，基本一致=7，类似=4，不相关=1 | 房屋建筑施工 | | |
| 建设规模 | 规模相当=10，规模较大=8，规模较小=5 | 建筑面积约2万㎡ | | |
| 结构形式 | 完全相同=10，类似=7，不同=4 | 框架结构 | | |
| 施工难度 | 难度相当=10，难度更高=9，难度较低=5 | | | |
| 时间远近 | 1年内=10，1-2年=8，2-3年=6 | | | |
| 业主类型 | 同行业=10，同性质=7，不同=4 | 国有企业 | | |
| 获奖情况 | 国家级奖=10，省级=8，市级=6，无=3 | | | |
| **加权总分** | | | | |

### 匹配度等级
- **9-10分**：高度匹配，重点展示
- **7-8分**：中度匹配，可以展示
- **5-6分**：低度匹配，凑数用
- **<5分**：不建议使用

## 业绩展示技巧

### 业绩表标准格式

| 序号 | 项目名称 | 建设单位 | 合同金额（万元） | 开工/竣工时间 | 项目规模 | 我方承担工作 | 备注 |
|---|---|---|---|---|---|---|---|
| 1 | XX大厦工程 | XX有限公司 | 8,500 | 2023.03-2024.06 | 建筑面积3.2万㎡，框架22层 | 施工总承包 | 获省优质工程奖 |
| 2 | | | | | | | |

### 展示技巧

**1. 排序策略**
- 把最匹配、最大、最好的业绩放在第一个
- 评委看业绩通常只看前1-2个，第一个印象最重要

**2. 突出亮点**
- 获奖业绩重点标注
- 规模大于本项目的要突出"规模大于本次招标项目"
- 同行业业主优先列出

**3. 简要说明**
- 每个业绩用1-2句话说明工程特点
- 说明我方在项目中的角色（总承包/分包/服务提供方）
- 不要长篇大论，表格为主

**4. 针对性描述**
- 招标文件看重什么，就在业绩里突出什么
- 比如招标文件强调"安全管理"，就列有安全文明施工样板的项目
- 招标文件强调"质量"，就列获过质量奖的项目

## 业绩证明材料要求

### 标准证明材料

| 材料类型 | 要求 | 注意事项 |
|---|---|---|
| 合同关键页 | 合同首页、签字盖章页、工程范围页、金额页 | 确保能看到项目名称、合同额、工期 |
| 竣工验收证明 | 竣工验收报告或竣工验收备案表 | 证明项目已完成 |
| 中标通知书 | 部分招标文件要求提供 | 证明项目是通过正规中标的 |

### 证明材料整理技巧
1. 每个业绩单独装订，编号对应业绩表序号
2. 合同页重要信息用荧光笔标注
3. 扫描件清晰，页码连续
4. 按业绩表顺序排列

## 业绩常见问题与避坑

### 高频问题

| 问题 | 后果 | 解决方案 |
|---|---|---|
| 业绩数量不够 | 不满足资格要求，废标 | 提前梳理业绩库，不够的话找联合体 |
| 业绩规模不够 | 扣分或不满足要求 | 找规模更大的业绩，或说明业绩更复杂 |
| 业绩时间超期 | 不算有效业绩 | 找时间范围内的，或确认时间起算点 |
| 类似性不符 | 评委不认可，白列 | 严格按招标文件对"类似"的定义筛选 |
| 证明材料不全 | 业绩不被认可 | 提前和公司档案部门对接，准备齐全 |
| 业绩主体不符 | 母子公司业绩借用无效 | 确认招标文件是否允许子公司业绩 |

### 避坑 Checklist

- ☐ 业绩数量是否满足招标文件最低要求？
- ☐ 每个业绩的规模是否都达标？
- ☐ 业绩时间是否都在要求范围内？
- ☐ 业绩类型是否符合"类似工程"定义？
- ☐ 证明材料（合同+验收）是否齐全？
- ☐ 业绩表和证明材料是否一一对应？
- ☐ 是否把最好的业绩放在了第一位？
- ☐ 是否有业绩合同额大小写不一致的问题？
- ☐ 项目经理业绩是否单独列出了？（有些招标要求项目经理业绩）
- ☐ 业绩数量是否刚好？（不要多也不要少）

## 附：业绩匹配快速评估脚本

```python
# 业绩匹配度快速评估
def evaluate_performance(project_requirements, performance):
    """
    project_requirements: dict，项目要求
    performance: dict，单个业绩
    返回匹配度得分
    """
    score = 0
    
    # 类型匹配 30%
    if performance["type"] == project_requirements["type"]:
        score += 30
    elif "similar" in performance["type"]:
        score += 20
    
    # 规模匹配 25%
    if performance["scale"] >= project_requirements["min_scale"]:
        score += 25
    
    # 时间远近 15%
    if performance["years_ago"] <= 1:
        score += 15
    elif performance["years_ago"] <= 2:
        score += 10
    elif performance["years_ago"] <= 3:
        score += 5
    
    # 其他维度省略...
    
    return score

# 使用示例
requirements = {
    "type": "房屋建筑",
    "min_scale": 5000,  # 万
    "max_years": 3
}

performances = [
    {"name": "项目A", "type": "房屋建筑", "scale": 8000, "years_ago": 1},
    {"name": "项目B", "type": "市政工程", "scale": 6000, "years_ago": 2},
]

for p in performances:
    score = evaluate_performance(requirements, p)
    print(f"{p['name']}: 匹配度 {score}分")
```
