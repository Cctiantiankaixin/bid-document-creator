# 官方招标文件标准与评标办法参考（训练素材）

> 本文件为技能"自主训练"产出，素材来源：国家发改委会同九部委《标准施工招标文件》及系列标准招标文件（2017版）、财政部令第87号《政府采购货物和服务招标投标管理办法》、以及湖南/广东/河南/江苏等地公共资源交易中心与政府采购网公开发布的真实招标文件及评标办法范本。
> 用途：让标书制作锚定官方口径，避免出现与现行招投规范相悖的结构、措辞和合规判断。

---

## 1. 中国招标文件官方体系

| 体系 | 主管/发布 | 适用 | 关键文件 |
|---|---|---|---|
| 依法必须招标的工程项目 | 发改委+九部委 | 工程建设（施工、货物、勘察、设计、监理、工程总承包） | 《标准施工招标文件》(2007/2017版)、《标准设备/材料/勘察/设计/监理/工程总承包招标文件》(2017版，2018年施行) |
| 政府采购 | 财政部 | 各级国家机关、事业单位、团体组织的货物、工程、服务采购 | 财政部令第87号《政府采购货物和服务招标投标管理办法》 |
| 地方范本 | 各省市公共资源交易中心/住建厅 | 房建市政等地方项目 | 如《房屋建筑和市政基础设施工程施工招标文件示范文本(2017年版)》 |

**使用规则**：标准文本"正文和前附表，除以空格标示的由招标人填空的内容、选择性内容和可补充内容外，均应不加修改地直接引用"。即投标人看到的"投标人须知正文+前附表"是刚性框架，标书必须以此为准响应。

## 2. 招标文件四大核心章节（必须精读）

任何一份招标文件，请优先吃透以下四章，其余章节可快速过：

1. **投标人须知（前附表 + 正文）**
   - 前附表集中列明：项目概况、资格要求、投标截止/开标时间地点、投标有效期、保证金、最高限价、分包、评标办法指向、否决条款等关键信息。
   - 正文为通用规则，前附表是对正文的填空与选择，**以前附表为准**。
   - 87号令第二十条：不允许偏离的**实质性要求和条件必须加黑加粗**醒目标明——这些是废标红线。

2. **评标办法（前附表 + 正文 + 附件）**
   - 前附表须列明**全部评审因素和评审标准**，并标明"投标人不满足即导致投标被否决"的全部条款（常作为附件B"废标/否决条件"）。
   - 这是评分点映射的唯一依据。

3. **合同条款及格式（通用 + 专用条款）**
   - 重点看**专用合同条款**：付款方式、交货/工期、质保期、违约责任、变更估价原则——商务承诺不得与之冲突。

4. **技术标准和要求（货物需求一览表、技术参数、售后服务要求）**
   - 投标人最关心的技术硬指标来源，须逐条做技术响应/偏离表。

5. **投标文件格式（资格/价格/商务/技术四部分）**
   - 各招标项目格式不同但大类一致，标书组成须严格按此分卷分册。

## 3. 评标办法体系对比

| 类别 | 方法 | 适用场景 | 中标逻辑 |
|---|---|---|---|
| 工程（依法招标） | 经评审的最低投标价法 | 技术标准通用、施工难度低 | 满足实质要求且经评审的投标价最低 |
| 工程（依法招标） | 综合评估法 | 技术复杂或规模大（如总承包>5000万） | 各评审因素加权得分最高 |
| 工程（依法招标） | 合理低价法 | 通用性强的工程 | 在合理低价范围内择优 |
| 政府采购 | 最低评标价法 | 标准统一、货源充足 | 满足实质要求且报价最低 |
| 政府采购 | 综合评分法 | 绝大多数货物/服务项目 | 量化指标评审得分最高 |

**客观分 vs 主观分**：
- 客观分（资质等级、业绩数量、认证证书）：准确对应即可，不得遗漏。
- 主观分（方案优劣、服务承诺）：按等级给分，要在内容中主动铺垫"优级锚点"。

## 4. 综合评分法分值构成规律（真实样本）

| 项目类型 | 分值构成（真实案例） | 规律 |
|---|---|---|
| 工程施工（湖南范本） | 技术方案 J1 0.05~0.30，企业资信及履约能力 J2 0.35~0.45，投标报价 J3 0.35~0.50 | 报价权重最高，资信次之 |
| 政府采购货物（87号令） | 价格分占比 **≥30%**，技术+商务≤70% | 价格下限受法规约束 |
| 政府采购服务（87号令） | 价格分占比 **≥10%** | 服务类允许低价权重更低 |
| 服务类（广州应急） | 技术 60 / 商务 25 / 价格 15 | 技术主导 |
| 服务类（广州公园管养） | 技术 40 / 商务 30 / 价格 30 | 技术主导 |
| 运维服务（江苏徐圩） | 价格 60 / 商务 10 / 技术 30 | 价格主导（含偏离扣分） |

**制作方向**：技术/方案分占比越高，篇幅越要向技术方案倾斜（工程可达30%权重→展开40%篇幅；服务可达60%→占主体）；价格分由报价本身决定，标书只须确保准确、不超最高限价。

## 5. 报价得分计算公式（三种主流）

### 5.1 低价优先法（货物/服务政府采购最常用）
```
评标基准价 = 满足要求且报价最低的投标报价
投标报价得分 = (评标基准价 / 投标报价) × 价格权重分值
```
报价超最高限价（招标控制价）→ 按无效标/否决投标处理。

### 5.2 偏离扣分法（工程常用）
```
评审基准价 A：有效报价≥7家取由低到高5家均值；4-6家取次低价；<4家取最低价
评审价每高于基准价 1% → 扣 0.3 分
评审价每低于基准价 1% → 扣 0.1 分
不足1%按插入法计算，结果四舍五入保留两位小数
```

### 5.3 随机抽取参数法（部分省市工程）
```
基准价 Y = A×(1-α)×60% + B×(1-β)×40%
A = 有效报价中 ≥ X(1-10%) 的报价算术平均值
B = 最高投标限价
α ∈ {0,1%,2%,3%}，β ∈ {3%,3.5%,4%,4.5%,5%,5.5%,6%}，开标时随机抽取
投标报价 < 基准价92% → 报价得分计 0（防低于成本恶意报价）
```

> 报价部分标书撰写只需"如实填表、大小写一致、计算准确、不超限价"，具体计分由评标系统完成，但须在商务部分明确"我方报价未超过最高投标限价"。

## 6. 初步评审：否决投标三表

开标后、详细评分前，先过三关，任一不满足即**否决（废标）**，不再进入评分：

### 6.1 形式评审标准（真实字段）
- 投标人名称与营业执照等证件一致
- 投标文件签字、盖章符合招标文件要求
- 投标文件格式符合"投标文件格式"章节规定
- 报价唯一（只能有一个有效报价）

### 6.2 资格评审标准（真实字段）
- 营业执照：具备有效营业执照（或三证合一）
- 法定代表人身份证明 / 授权委托书
- 资质要求：满足投标人须知前附表规定的资质等级
- 财务证明：财务状况报告
- 纳税证明 / 社保证明：依法缴纳税收和社保的良好记录
- 无重大违法记录声明：参加采购活动前3年内在经营活动中无重大违法记录书面声明
- 信用查询：在"信用中国""中国政府采购网"未被列入失信、重大税收违法、政府采购严重违法失信名单（提供截图加盖公章）
- 资料真实有效承诺

### 6.3 响应性评审标准（真实字段）
- 采购/招标内容符合前附表规定
- 服务期限 / 工期符合规定
- 质量标准符合规定
- 投标有效期符合规定
- 投标文件未附有招标人不能接受的条件

> 制作方向：以上清单是合规检查的"否决红线"，须 100% 满足。详见 `references/compliance-checklist.md`。

## 7. 中小企业价格扣除政策（政府采购）

依据《关于进一步加大政府采购支持中小企业力度的通知》（财库〔2022〕19号）：

| 企业类型 | 货物项目扣除 | 服务项目扣除 |
|---|---|---|
| 小型、微型企业 | 6%（部分省市） | 10%~20% |
| 残疾人福利性单位 | 视同小微，6% | 视同小微，10%~20% |
| 监狱企业 | 视同小微，6% | 视同小微，10%~20% |

- 扣除仅享受一次，不重复。
- 须提供《中小企业声明函》（格式见招标文件）。
- 以扣除后的价格参与评审、计算基准价。

> 制作方向：若投标人为小微/残疾人/监狱企业，**必须主动在商务部分附《中小企业声明函》**，否则白白损失价格得分。

## 8. 实质性条款标注规则

- 87号令第二十条：对于不允许偏离的**实质性要求和条件**，采购人/代理机构须在招标文件中以**醒目方式（加黑加粗）**标明。
- 投标人须知前附表常设"投标人须注意"栏，汇总否决情形。
- 制作方向：凡是加黑加粗的条款，技术/商务响应中必须**逐条明确"完全响应，无偏离"**，不得遗漏，遗漏即触发否决。

## 9. 主观评分项等级表述（官方口径）

多地评标办法对主观分采用统一等级锚定，撰写时应主动对齐这些等级语言：

| 等级 | 百分比区间 | 对应措辞 |
|---|---|---|
| 优 | 90%~100% | "综合对比优""内容全面合理、针对性强、可行性高" |
| 良 | 80%~89% | "综合对比次之""较清晰、较合理" |
| 中 | 70%~79% | "综合对比一般""具备适用性" |
| 可 | 60%~69% | "有提供但不全面、缺乏操作性" |
| 差 | <60% | "未提供或其他不得分" |

**常用句式**（直接对标评审表）：
> "评委根据……由高至低横向评分：内容全面合理、针对性与可行性强的得 X 分；较合理可行的得 Y 分；一般得 Z 分；较差得 0 分。"

> 制作方向：把"我们最专业"式的溢美之词，改写为"在……维度达到优级标准（具体表现：……）"的可分级表述，让评委易于给高分。详见 `references/writing-guide.md` 的"表述制作方向"章节。
