## 标书格式规范

### 1.1 纸张与版面

| 项目 | 标准要求 | 备注 |
|---|---|---|
| 纸张规格 | A4纸（210mm × 297mm） | 纵向排版 |
| 打印颜色 | 黑白打印（彩色要求除外） | 暗标通常要求黑白 |
| 页码 | 从正文开始连续编号 | 暗标可能要求无页码 |
| 页眉页脚 | 按招标文件要求设置 | 暗标通常禁止页眉页脚 |

### 1.2 页边距标准

不同地区略有差异，常见标准：

| 边距位置 | 常用标准 | 工程类常见 | 服务类常见 |
|---|---|---|---|
| 上边距 | 2.5 cm | 2.5 cm | 2.5 cm |
| 下边距 | 2.0 - 2.5 cm | 2.54 cm | 2.0 cm |
| 左边距 | 2.0 - 3.17 cm | 3.17 cm（装订侧） | 2.0 cm |
| 右边距 | 2.0 - 2.54 cm | 2.54 cm | 2.0 cm |

**注意：** 以招标文件具体要求为准，误差不超过10%。

### 1.3 字体字号标准

| 文档部分 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 大标题（章） | 黑体/宋体 | 二号/小二 | 加粗 |
| 二级标题 | 黑体/宋体 | 小三/三号 | 加粗 |
| 三级标题 | 黑体/宋体 | 四号 | 加粗 |
| 正文 | 宋体 | 小四/四号 | 常规 |
| 表格内文字 | 宋体 | 五号 | 常规 |
| 数字和英文 | Times New Roman | 同正文 | 常规 |

**暗标特殊要求：**
- 全部使用宋体，不得出现加粗、加色、倾斜、下划线
- 不得出现任何投标人标识信息
- 不得设置封面、目录
- 不得有底纹、水印

### 1.4 段落与行距

| 项目 | 标准要求 |
|---|---|
| 行距 | 1.5倍行距 或 固定值28-30磅 |
| 首行缩进 | 2字符 |
| 对齐方式 | 两端对齐 |
| 段前段后 | 不设置空行 或 0.5行 |
| 字符间距 | 标准 |

### 1.5 目录要求

- 自动生成目录，页码准确
- 目录层级一般到三级标题
- 目录页码与正文页码必须一致
- 暗标通常不要求目录

## 装订与密封要求

### 2.1 正副本要求

| 项目 | 标准要求 |
|---|---|
| 正本数量 | 通常1份 |
| 副本数量 | 通常2-5份（按招标文件要求） |
| 标记方式 | 封面右上角清晰标注"正本"或"副本" |
| 不一致处理 | 副本与正本不一致时，以正本为准 |

### 2.2 装订方式

| 装订类型 | 适用场景 | 要求 |
|---|---|---|
| 胶装 | 大多数正式标书 | 牢固、平整、不散页 |
| 活页装订 | 部分服务类项目 | 可拆卸，便于评委翻阅 |
| 骑马钉 | 小型简单标书 | 少用，正式项目不推荐 |

**注意：** 严格按招标文件要求的装订方式执行，擅自更改可能被判定为形式不符。

### 2.3 密封要求

**纸质标书密封标准流程：**

1. **内封：**
   - 正本单独密封袋
   - 副本单独密封袋（或正副本合封，按要求）
   - 密封袋封面注明：项目名称、项目编号、投标人名称、"开标前不得开启"字样

2. **外封：**
   - 将正本密封袋、副本密封袋、电子版密封袋统一装入外密封袋
   - 外封袋封面注明：招标人名称、地址、项目名称、投标人名称、地址

3. **封口盖章：**
   - 密封袋所有封口处加盖投标人公章
   - 骑缝处也要盖章
   - 缺一个封口章都可能被拒收

### 2.4 电子版介质要求

| 介质类型 | 要求 |
|---|---|
| U盘/光盘 | 内容与纸质标书完全一致 |
| 文件格式 | 通常要求PDF格式（不可编辑）+ Word格式（可编辑） |
| 标签标注 | 封面注明项目名称、投标人名称 |
| 密封方式 | 单独密封袋，与纸质标书一同递交 |

## 签字盖章要求

### 3.1 必须盖章的位置

| 位置 | 盖章类型 | 说明 |
|---|---|---|
| 标书封面 | 单位公章 | 正本、副本都要盖 |
| 投标函 | 单位公章 + 法定代表人章/签字 | 核心文件 |
| 法定代表人身份证明 | 单位公章 | 必须 |
| 授权委托书 | 单位公章 + 法定代表人签字 + 被授权人签字 | 三方都要 |
| 投标保证金缴纳凭证 | 单位公章（复印件） | 核对原件 |
| 报价一览表/开标一览表 | 单位公章 | 核心文件 |
| 商务条款响应表 | 单位公章 | 每页或骑缝 |
| 技术方案最后一页 | 单位公章 | 部分项目要求 |
| 资格证明文件 | 单位公章（复印件） | 营业执照、资质证书等 |
| 骑缝章 | 单位公章 | 整本标书侧面骑缝 |

### 3.2 必须签字的位置

| 位置 | 签字人 | 说明 |
|---|---|---|
| 投标函 | 法定代表人或授权代表 | 手签原件 |
| 授权委托书 | 法定代表人 + 授权代表 | 双方都要签 |
| 法定代表人身份证明 | 法定代表人 | 手签 |
| 报价文件 | 法定代表人或授权代表 | 部分项目要求 |
| 修改处 | 授权代表 | 所有修改补签 |

### 3.3 骑缝章要求

- **盖法：** 整本标书侧边均匀盖章，覆盖所有页面边缘
- **要求：** 印章完整连贯，每一页都能看到部分印章
- **范围：** 正本每本都要盖，副本按要求
- **注意：** 不要只盖一半，不要漏页

### 3.4 签字盖章常见错误

| 错误 | 后果 | 防范措施 |
|---|---|---|
| 漏盖骑缝章 | 形式评审不通过 | 装订后检查每本都盖了 |
| 授权委托书缺一方签字 | 无效 | 核对三方签字 |
| 复印件未盖公章 | 不认可 | 所有复印件加盖鲜章 |
| 修改处未补签 | 视为无效修改 | 检查所有修改痕迹 |
| 用章错误（部门章代替公章） | 无效 | 确认用章类型 |

## 电子招投标提交要求

### 4.1 前期准备

| 准备项 | 说明 |
|---|---|
| 平台注册入库 | 在项目所属公共资源交易平台完成企业实名注册 |
| CA数字证书 | 办理USBKey（CA锁），确认在有效期内 |
| 投标客户端 | 从平台下载指定版本的投标文件制作工具 |
| 驱动安装 | 安装CA驱动和客户端控件，重启电脑 |

### 4.2 电子投标文件制作

1. **使用指定客户端**：必须用平台官方投标文件制作软件
2. **文件加密**：用CA证书对投标文件进行加密
3. **电子签章**：在客户端内完成电子签章（相当于纸质盖章）
4. **文件检查**：制作完成后预览检查，确认格式和内容无误
5. **备份文件**：保留未加密版本和加密版本各一份

### 4.3 上传与解密

| 环节 | 要求 |
|---|---|
| 上传时间 | 截止时间前完成上传，预留足够时间（建议提前1天） |
| 上传方式 | 通过平台投标系统上传加密后的投标文件 |
| 解密时间 | 开标后规定时间内（通常30分钟内）完成解密 |
| 解密工具 | 使用同一把CA证书进行解密 |
| 解密失败 | 及时联系平台技术支持，不要重复尝试 |

### 4.4 电子标常见问题

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 上传失败 | 网络问题/文件过大 | 换网络，分卷压缩 |
| 解密失败 | CA证书不对/过期 | 确认证书有效期，联系技术支持 |
| 签章不显示 | 客户端版本不对 | 下载最新版客户端 |
| 文件格式错误 | 用错制作工具 | 用平台指定客户端重新制作 |

## 常见废标风险点

### 🔴 高危（直接废标）

1. **未按要求密封** — 封口处未盖章、密封袋标记不清
2. **签字盖章缺失** — 投标函未签字盖章、授权委托书无效
3. **正副本份数不足** — 少一份都不行
4. **逾期送达** — 超过截止时间一秒都不行
5. **报价未按要求格式** — 大小写不一致、未按表格填写

### 🟡 中危（扣分或要求澄清）

1. **格式不规范** — 字体、行距、页边距不符合要求
2. **目录页码错误** — 目录与正文页码对不上
3. **装订不牢固** — 散页、脱页
4. **电子版介质损坏** — U盘读不出、光盘刮花

### 🟢 低危（交付前修正）

1. **页眉页脚不统一**
2. **页码位置不一致**
3. **表格边框不完整**

## 附：标书格式检查 Checklist

**装订前检查：**
- ☐ 正本、副本份数是否正确？
- ☐ 封面是否标注"正本"/"副本"？
- ☐ 装订方式是否符合要求？
- ☐ 骑缝章是否盖好（每本都要）？
- ☐ 所有要求签字的位置都签了吗？
- ☐ 所有要求盖章的位置都盖了吗？
- ☐ 所有修改处都补签了吗？
- ☐ 电子版U盘/光盘准备好了吗？
- ☐ 密封袋封口都盖章了吗？
- ☐ 密封袋封面信息填写完整了吗？

**电子标检查：**
- ☐ CA证书在有效期内吗？
- ☐ 用的是最新版投标客户端吗？
- ☐ 电子签章都完成了吗？
- ☐ 文件加密成功了吗？
- ☐ 提前上传测试了吗？
- ☐ 开标解密工具准备好了吗？
